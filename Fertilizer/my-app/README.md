# Bhoomi Bloom 🌿

> **Empowering Agriculture Through AI & Innovation**

Bhoomi Bloom is a next-generation AI-powered smart agriculture ecosystem. It seamlessly bridges the gap between modern technology and traditional farming by providing an ultra-premium e-commerce marketplace and an intelligent AI farming assistant.

![Bhoomi Bloom Banner](src/assets/auth_cinematic_bg.jpg)

## 🚀 Features

### 🛒 Premium E-Commerce Marketplace
- **Massive Catalog:** Over 60+ products across 5 domains (Seeds, Machinery, Tools, Irrigation, Organic Fertilizers).
- **Secure Checkout:** Complete checkout flow with order summary and encrypted payment UI.
- **Smart Filtering:** Advanced sorting by Price (Low/High), Rating, and Categories.

### 🤖 Bhoomi AI Assistant
- **Floating Chat Widget:** A persistent, modern AI interface.
- **Quick Actions:** One-click prompts for "Scan Plant", "Crop Advice", "Weather", and "Fertilizer Help".
- **Intelligent Responses:** Simulated contextual AI advice for modern farming.

### 📊 Advanced Dashboards
- **Farmer Dashboard:** Track orders, manage wishlists, and view personalized AI crop recommendations.
- **Admin Dashboard:** Monitor total revenue, active users, order statistics, and manage inventory via a professional data grid.

### 🎁 Gamification
- **Spin & Win Wheel:** An interactive daily rewards system to earn "Bhoomi Points".
- **Loyalty Rewards:** Earn points on checkout to encourage sustainable farming purchases.

## 🛠 Tech Stack
- **Frontend Framework:** React + Vite
- **UI Library:** Ant Design (antd)
- **Routing:** React Router v6
- **Styling:** Custom CSS + Glassmorphism Aesthetics
- **Architecture:** Scalable component-driven design (`/components`, `/pages`, `/hooks`, `/services`, `/utils`)

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/bhoomi-bloom.git
   cd bhoomi-bloom/my-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   ```bash
   cp .env.example .env
   # Add your specific API keys to .env
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
