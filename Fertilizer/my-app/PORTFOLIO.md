# Project Showcase: Bhoomi Bloom

**Role:** Lead Full-Stack Developer / UI/UX Engineer  
**Tech Stack:** React, Vite, Ant Design, Custom CSS (Glassmorphism)

## 📌 Problem
Traditional farmers face significant hurdles in accessing high-quality agricultural supplies and lack real-time agronomic guidance to maximize their yield sustainably. Existing agriculture e-commerce platforms suffer from poor user experiences, outdated designs, and lack intelligent features.

## 💡 Solution
I architected and developed **Bhoomi Bloom**, a next-generation AI-powered agriculture marketplace. The platform combines a luxury E-commerce experience with an integrated AI Farming Assistant, empowering farmers with data-driven crop recommendations and seamless access to premium organic supplies and smart machinery.

## 🌟 Key Features Developed

1. **AI Farming Assistant:** 
   Engineered a persistent, floating chatbot module that simulates real-time plant disease detection, hyper-local weather alerts, and precision fertilizer scheduling using context-aware quick actions.

2. **Ultra-Premium E-Commerce Flow:** 
   Designed and built a massive, dynamically filtered 60+ product catalog complete with a secure checkout flow, shopping cart, wishlist functionality, and gamified loyalty points.

3. **Role-Based Analytics Dashboards:**
   - **Farmer Portal:** Personalized dashboard featuring order tracking, saved items, and actionable AI recommendations.
   - **Admin Console:** High-level analytics interface utilizing Ant Design charts and data grids to track revenue, user acquisition, and inventory management.

4. **Interactive Gamification:**
   Implemented a custom "Spin & Win" CSS-animated fortune wheel to drive daily user engagement and reward sustainable farming practices.

## 📈 Impact
Bhoomi Bloom demonstrates a highly scalable React architecture with strict separation of concerns (`/hooks`, `/services`, `/utils`). The project showcases professional-grade UI/UX sensibilities, seamlessly blending nature-inspired aesthetics with modern luxury SaaS design principles.
